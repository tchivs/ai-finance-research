## 推荐用法

1. 用 `10-SYNTHESIS.md` 建立全局认识。
2. 用 `17-落地路线图.md` 确定实施顺序和验收标准。
3. 用 `18-模式决策矩阵.md` 处理技术分叉。
4. 回到专题文档和项目 `DEEP-ANALYSIS.md` 核对证据、风险与限制。
5. 开始实现前，用 `19-首批源码落地验证.md` 检查关键模式的真实代码边界。
6. 用 `20-开发实施TODO.md` 跟踪任务、阶段门禁和验收证据。
7. 用 `21-项目价值评估与方法论.md` 判断项目优先级、Top 10 参考和最值得吸收的方法论。

本资料库提供研究结论和设计参考，不替代生产环境中的安全评审、数据验证、合规检查和性能测试。
